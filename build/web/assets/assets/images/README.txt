Place any local images you want to bundle with the app here (e.g. a
poster/fallback frame for the hero video, or your own service photos).

By default, service photo carousels use placeholder network images
(picsum.photos). To use local images instead, put files here and update
the `photos` list for each service in lib/main.dart to reference
'assets/images/your-file.jpg' with an Image.asset instead of
Image.network in lib/widgets/photo_carousel.dart.
